# 更新日志（CHANGELOG）

本文档记录「每日早安」闹钟 App 各版本变更。版本号遵循 `主版本.次版本.修订`。

## 2.1.1 — 2026-08-31 · 响铃可靠性：息屏准时 + 异常不卡死

### 修复
- **息屏不响铃**（真机实证：闹钟定 08:01、精确=true，实际延迟到 08:23:53 才补投）：
  调度改为 `setAlarmClock` 优先——官方保证系统永不调整其投递时间、必要时退出低功耗模式；
  降级链 `setExactAndAllowWhileIdle → setWindow → setAndAllowWhileIdle`。
  `canScheduleExact` 兼认 `USE_EXACT_ALARM`（Android 14+ `SCHEDULE_EXACT_ALARM` 默认拒绝）。
- **到点到出声的空档被系统休眠打断**：新增 `RingWakeLock`（`PARTIAL_WAKE_LOCK` 覆盖到点 → 出声）。
- **重复到点叠加播放**：新增 `RingGuard`（设备保护存储记录 triggerAt，60s 内重复到点丢弃，主判重在 Receiver）。
- **Doze 下空等网络**：缓存为空且设备处于 Doze 时跳过现场同步，直走兜底铃声，不再白等 8 秒。

### 加固（QA 观察项 O1）
- 响铃协程新增 `CoroutineExceptionHandler` 兜底：任何逸出的未捕获异常统一降级到兜底铃声，
  每场只降级一次，避免异常循环打转。
- 停止 / 贪睡收尾流程：读设置或续期调度失败也必定撤前台、停服务，
  用户按下的「停止」不会再卡在「通知还在、关不掉」。
- 贪睡注册优先保障：设置读取失败时退回默认间隔，绝不把用户静音丢弃。
- 逐点防护：主音频起播 / 重播 / 副音频起播与重启 / 渐弱收尾 / 蜂鸣循环
  各自 `runCatching` 兜底，单点失败不拖垮整场响铃。
- 副音频起播失败不再拖累主音频——跳过衬托立即起播主音频。
- 服务进前台或播放器创建失败不再让整场响铃崩溃（通知权限被撤等场景）。

### 内部
- 清单补齐 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`，receiver/service 标 `directBootAware`；
  通知渠道加锁屏可见 + 免打扰穿透。
- 服务 `startForeground` 先于 ExoPlayer 创建，避免在 Doze 唤醒短窗口内超时。

## 2.1.0 — 2026-08-30 · 播放体验全面可定制

### 新增
- **副音频衬托**：闹钟先循环播放背景音乐温柔唤醒，衬托结束自动起播视频音频并压低背景音，播完恢复续播 30 秒收场；副音频开关 / 文件选择（SAF 持久授权）/ 背景音量 / 压低音量 / 衬托时长（10 秒~10 分钟滑条）均可调。
- **副音频播放区间**：选中文件后可设起点/终点滑条（默认从头播到尾），循环只在选定区间内重复；换文件自动重置区间。
- **贪睡间隔自由调节**：1~30 分钟滑条（原 5/10/15 三档）。
- **音量渐强时长可调**：5~60 秒滑条（原固定 20 秒）。
- **播完自动重播**：整段播完后若未手动停止，自动从头再播，直到手动关闭。
- **时间选择器双模式**：表盘 ⇄ 键盘输入一键切换，直接键入时间更快。

### 内部
- 设置页统一「标签 + 当前值 + 滑条」组件（LabeledSlider）。
- 契约测试同步新参数口径（贪睡范围 / 渐强时长 / 裁剪哨兵）。
- 版本号对齐（APP_VERSION 2.0.0 → 2.1.0，补录 2.0.0 条目）。

## 1.2.0 — 2026-08-29 · V2 改版

### 新增
- **博主管理**：设置页可粘贴抖音主页链接 / sec_uid，自动解析并校验，切换音频来源（换博主自动清缓存）。
- **内置使用说明**：设置页新增「使用说明」页，含快速上手 / 权限说明 / 同步与数据源 / 响铃操作 / 常见问题五个板块。
- **UI 全面重设计**（Material 3 Expressive「晨昏」主题）：
  - 主页：大号倒计时数字 + 日出进度环 + 状态卡片 + 精致权限警示卡
  - 响铃页：夜空渐变背景 + 日出光晕（随音量渐强增亮）+ 滑动停止（防误触）
  - 设置页：分组卡片化 + 图标条目 + 同步状态行
- **动效系统**：spring 弹簧动效 token 化（Motion.kt / Shape.kt）。

### 数据源（重大突破）
- 确认抖音作品接口无需 `a_bogus` 签名，**登录 Cookie + UA/Referer 直连**即可获取视频列表。
- 自建轻量代理 `dyproxy`（纯 Node，无浏览器）部署至云服务器，返回 App 兼容的 JSON Feed。
- App 放行明文 HTTP（`network_security_config.xml`）。

### 修复
- 设置页缺失 `setValue` 委托 import 导致的编译错误。
- 图标弃用警告（改用 `AutoMirrored` 版本）。
