# 更新日志（CHANGELOG）

本文档记录「每日早安」闹钟 App 各版本变更。版本号遵循 `主版本.次版本.修订`。

---

## 1.2.0 — 2026-08-29 · V2 改版

### 新增
- **博主管理**：设置页可粘贴抖音主页链接 / sec_uid，自动解析并校验，切换音频来源（换博主自动清缓存）。
- **内置使用说明**：设置页新增「使用说明」页，含快速上手 / 权限说明 / 同步与数据源 / 响铃操作 / 常见问题五个板块。
- **UI 全面重设计**（Material 3 Expressive「晨昏」主题）：
  - 主页：大号倒计时数字 + 日出进度环 + 状态卡片 + 精致权限警示卡
  - 响铃页：夜空渐变背景 + 日出光晕（随音量渐强增亮）+ 滑动停止（防误触）
  - 设置页：分组卡片化 + 图标条目 + 同步状态行
- **动效系统**：spring 弹簧动效 token 化（Motion.kt / Shape.kt）。

### 数据源（重大突破）
- 确认抖音作品接口无需 `a_bogus` 签名，**登录 Cookie + UA/Referer 直连**即可获取视频列表。
- 自建轻量代理 `dyproxy`（纯 Node，无浏览器）部署至云服务器，返回 App 兼容的 JSON Feed。
- App 放行明文 HTTP（`network_security_config.xml`）。

### 修复
- 设置页缺失 `setValue` 委托 import 导致的编译错误。
- 图标弃用警告（改用 `AutoMirrored` 版本）。

## 1.0.3 — 2026-08-29 · 闹钟可靠性加固 + 兜底

### 修复（F1-F5）
- F1：广播触发补发高优先级兜底通知（服务被拦截也能点进响铃页），启动失败不再静默。
- F2：选片/播放所有异常路径强制进入兜底并设置响铃状态，杜绝页面空白闪退。
- F3：响铃页 3 秒防闪退保护 + 加载占位。
- F4：双路径拉起响铃页（显式 `startActivity` + 全屏通知），不再只依赖 full-screen intent。
- F5：主页权限缺失常驻提醒条（通知 / 全屏显示 / 精确闹钟）。

### 新增
- 响铃页「打开抖音看最新视频」按钮（`ACTION_VIEW` 直达博主主页）。

## 1.0.0 — 2026-08-27 · 首个可用版本

- 每日闹钟（精确闹钟 + 重启恢复 + 响完自续期）。
- 到点播放抖音「每日早安」当天最新视频音频（当天未更新则播最近一期并提示）。
- 四级兜底：本地缓存 → 系统闹钟铃声 → 系统铃声 → 蜂鸣，绝不哑火。
- 后台预下载（每天 05:30 / 21:00 同步并缓存最近 2-3 条）。
- 音量渐强（20 秒 30%→100%）、贪睡（5/10/15 分钟，默认 10）。
- 锁屏全屏响铃页（大字时间 + 标题 + 播放/暂停/稍后/停止）。
- HyperOS 权限分步引导（自启动 / 省电无限制 / 精确闹钟 / 通知 / 全屏显示）。
- RSSHub 数据源地址可配置。
- 68 个 JVM 单元测试（选片 / 时间 / 解析 / 常量）。
