# 「每日早安」闹钟 App 使用说明书

版本：1.0.0　|　适用系统：Android 10+（推荐 Xiaomi HyperOS 3.0）　|　包名：com.goodmorning.alarm

---

## 一、这是什么

「每日早安」是一款**音频闹钟 App**：每天在你设定的时间，自动播放抖音博主「每日早安」（抖音号 92588861148）**当天最新视频的音频**；如果当天博主还没更新，就自动播放**最近一期**，并在界面上提示。

> 只播声音、不播画面——早上闭着眼也能听，无需打开抖音。

---

## 二、功能一览

| 功能 | 说明 |
|------|------|
| 每日闹钟 | 设定时间，每天重复；重启手机自动恢复 |
| 自动播放 | 到点自动播当天最新视频音频（音量渐强 20 秒 30%→100%） |
| 智能选片 | 当天更新 → 播当天；未更新 → 播最近一期并提示 |
| 四级兜底 | 本地缓存 → 系统闹钟铃声 → 系统铃声 → 蜂鸣音，**绝不哑火** |
| 本地预下载 | 每天 05:30 / 21:00 自动同步并缓存最近 2-3 条，早上没网也能播 |
| 稍后提醒 | 贪睡 5/10/15 分钟可选（默认 10） |
| 锁屏直达 | 锁屏状态响铃页直接弹出，大字时间 + 标题 + 控制按钮 |
| 权限引导 | 首次启动分步引导完成 HyperOS 所需全部权限 |

## 三、安装

### 方式一：Android Studio 构建（推荐，可长期自己改）

1. 安装 **Android Studio**（自带 JDK，无需另装）
2. `File → Open` 打开工程文件夹 `goodmorning-alarm`
3. 首次 Gradle Sync 会自动下载依赖（工程已内置**阿里云镜像**，国内网络可直连；若仍很慢，检查电脑是否开着 Clash 等代理，建议先退出）
4. 手机开启「开发者模式」+「USB 调试」，数据线连接电脑
5. 点 **▶ Run** 安装到手机

**已知环境坑（Windows Git Bash）**：若在命令行用 `./gradlew` 报 `cygpath: unknown option -- quote`，改用以下命令直接编译：

```bash
export JAVA_HOME="/f/project_develop/IntelliJ IDEA 2024.1/jbr"   # 指向任意 JDK 17
"$JAVA_HOME/bin/java" -Dorg.gradle.appname=gradlew \
  -classpath gradle/wrapper/gradle-wrapper.jar \
  org.gradle.wrapper.GradleWrapperMain :app:compileDebugKotlin
```

### 方式二：直接安装 APK

拿到 `app-debug.apk` 后传到手机，点击安装（需在手机设置中允许「安装未知来源应用」）。

## 四、首次启动：5 步权限（决定闹钟能否正常响，务必完成）

打开 App 后按引导页逐项操作（每个按钮都会跳到对应系统设置页）：

| 步骤 | 权限 | HyperOS 手动路径 |
|------|------|-----------------|
| ① | 通知权限 | 弹窗直接点「允许」 |
| ② | 精确闹钟 | 系统弹窗允许；或 设置 → 隐私保护 → 特殊权限 → 闹钟和提醒 |
| ③ | 自启动 | 设置 → 应用设置 → 应用管理 → 每日早安 → 自启动（打开） |
| ④ | 省电策略 | 同上 → 省电策略 → 选「无限制」（否则可能被系统杀掉） |
| ⑤ | 全屏显示通知 | 特殊权限访问 → 全屏显示通知（打开，Android 14+ 才有此项） |

**额外建议**：在最近任务列表中下滑「每日早安」卡片并点击 🔒 上锁，防止误清后台。

## 五、日常使用

### 设置闹钟
主页 → 点击时间 → 选择时间 → 打开总开关 → 主页显示「下次响铃 HH:mm」。

### 设置页选项
| 选项 | 说明 |
|------|------|
| RSSHub 地址 | 视频数据源地址（默认 `https://rsshub.app`），见「常见问题 Q1」 |
| 贪睡时长 | 5 / 10 / 15 分钟 |
| 音量渐强 | 开/关（默认开） |
| 立即同步 | 手动触发一次「拉取列表 + 下载缓存」，用于验证 |
| 清除缓存 | 删除已下载视频，释放空间 |

### 响铃页按钮
- **暂停/继续**：控制播放（渐强会按剩余时间恢复）
- **稍后提醒**：按设定间隔再响一次
- **停止**：结束本次响铃，自动注册明天同一时间

## 六、工作原理（简单版）

```
05:30/21:00  自动同步：RSSHub 拉取「每日早安」最新视频列表
     ↓       下载最近 2-3 条视频到手机本地（缓存）
  设定时间    精确闹钟触发（AlarmManager，锁屏也能响）
     ↓
  选片：当天最新 → 无则最近一期
     ↓
  播放音频（音量渐强）→ 若本地文件损坏，逐级降级：
  本地缓存 → 系统闹钟铃声 → 系统铃声 → 蜂鸣音
```

- 闹钟**只依赖系统闹钟服务**，后台同步（WorkManager）只是提前备料，失败不影响响铃
- 重启手机后自动恢复闹钟；改系统时间也会触发重新校准

## 七、常见问题（FAQ）

**Q1：设置页「立即同步」报 EMPTY / PARSE / NETWORK 错误？**
公共 RSSHub 实例（rsshub.app）对抖音路由支持不稳定，这是已知现象，不影响闹钟响铃（会播缓存/铃声）。解决办法：
- 换其他公共实例地址（设置页修改 RSSHub 地址后重新同步）
- 推荐**自建 RSSHub**（见 Q2），一劳永逸

**Q2：怎么自建 RSSHub？**
在一台常开设备（旧电脑 / NAS / 云服务器）上部署：
```bash
# Docker 一键部署
docker run -d --name rsshub -p 1200:1200 diygod/rsshub
# 浏览器访问 http://<设备IP>:1200 看到页面即成功
# 把 App 设置页 RSSHub 地址改为 http://<设备IP>:1200
```
家用网络下手机和服务器在同一个 Wi-Fi 即可直接访问。

**Q3：早上没网 / 断网时还会响吗？**
会。播放的是提前下载好的本地缓存；即便缓存也失败，还有铃声和蜂鸣兜底，闹钟一定响。

**Q4：博主当天没更新怎么办？**
自动播放最近一期，响铃页提示「今日尚未更新，为你播放最近一期」。

**Q5：闹钟不准时 / 不响？**
依次检查：① 是否完成「自启动 + 省电无限制」；② 系统设置 → 精确闹钟权限是否允许；③ 是否把 App 加入了省电名单之外；④ 最近任务里是否被上锁。

**Q6：缓存占空间吗？**
最多保留最近 3 条视频（每条约 10-50MB），可在设置页手动清除。

**Q7：换手机 / 重装后设置会丢吗？**
闹钟时间、RSSHub 地址等设置需重新配置（未做云端同步）；缓存视频不迁移。
